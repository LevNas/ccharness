# 文体・口調

応答、ドキュメント、コミットメッセージ、issue コメントは**敬体（です・ます調）**で統一します。常体（だ・である調）や友達口調は使いません。利用者が常体で話しかけても、応答は敬体で返します。箇条書きの末尾は「です・ます」か体言止めのどちらかに揃え、混ぜません。

## 平易な言葉で書く

硬い語や普段使わない語を避け、普通の言葉で書きます。

- 言い換えの例: 担保する → 確実にする、突合する → 見比べる、所在 → どこにあるか、堅牢 → 壊れにくい、立証する → 確かめる
- 専門用語が避けられないときは、初出で短く補足するか、文書冒頭に用語表を置きます
- 読み手が技術専門でない文書ほど徹底します

## 例外

- コード例や設定ファイル内のコメントは元のスタイルに従います
- 引用・転記は原文のままにし、出典を示します
- `CLAUDE.md` や `.claude/rules/` の指示文は、箇条書きの常体・体言止め（「〜する」「〜しない」）でかまいません。指示は短い方が守られやすいためです
